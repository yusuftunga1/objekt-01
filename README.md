## ✨ Features

- 🏛️ **Bespoke Swiss Editorial & Museum Catalogue Layout**:
  - Precision typographic hierarchy utilizing **Space Grotesk**, **DM Sans**, and **DM Mono**.
  - Sub-hairline architectural grid system with subtle physical paper grain overlay.
  - Zero-clutter, content-first aesthetic inspired by Dieter Rams’ *"Weniger, aber besser"* philosophy.

- 🔊 **Live Web Audio API Acoustic Engine**:
  - Real-time harmonic frequency synthesis (216 Hz fundamental & 432 Hz organic room resonance).
  - Smooth exponential ramp gain staging with zero audio clipping.

- 🔬 **Three Interactive Real-Time Canvas Laboratories**:
  - **Dipol Wave Simulation (360°)**: Real-time figure-8 acoustic wavefront radiation with interactive SPL sound pressure probe.
  - **Roman Travertine Porosity Scanner**: Interactive cavern damping decay oscilloscope comparing Travertine, Cast Aluminum, and MDF Wood.
  - **1.2µm Mylar Diaphragm Physics**: Planar electrostatic wave dispersion with adjustable excitation frequency (40 Hz – 1,200 Hz) and polarization voltage (1.5 kV – 6.5 kV).

- 🎛️ **Kinetic Stepped Attenuator & CNC Aluminum Dial**:
  - 360-degree interactive rotatable CNC AL-7075 dial running on virtual ruby bearings.
  - 64-step discrete Vishay R-2R ladder relay emulation with angular velocity telemetry and calibrated gain presets.

- 📜 **Scroll-Reactive Typographic Manifesto**:
  - Smooth word-by-word opacity and scale interpolation tied to scroll physics (`cubic-bezier(0.16, 1, 0.3, 1)`).
  - Dynamic reading focus progress telemetry bar.

- 🖼️ **Sticky Horizontal Light & Architecture Gallery**:
  - Multi-plate architectural case studies (Zürich Pavillon, Villa Kronenhalle, Tivoli Quarries).
  - Smooth vertical-to-horizontal viewport momentum transformation.

- 🛡️ **Hardened Enterprise Web Security**:
  - Sıkı **Content-Security-Policy (CSP)**: İzinli kaynak filtreleme ve inline kısıtlamaları.
  - **DOMPurify-grade SVG Sanitizer**: SVG enjeksiyonuna karşı etiket/nitelik filtreleme.
  - `X-Frame-Options: DENY` (Anti-Clickjacking) & `X-Content-Type-Options: nosniff`.
  - Input pattern validation ve sanitizer ile korunmuş özel dinleme rezervasyon modalı.

## 🚀 Quick Start

No build tools, bundlers, or package installations required. Runs immediately in any modern browser.

### Clone & Run

```bash
# 1. Depoyu klonlayın
git clone https://github.com/yusuftunga1/objekt-01.git

# 2. Proje dizinine girin
cd objekt-01

# 3. index.html dosyasını tarayıcınızda açın
start index.html
```

Or serve via any local static server:

```bash
# Python
python -m http.server 3000

# Node.js
npx serve .
```
